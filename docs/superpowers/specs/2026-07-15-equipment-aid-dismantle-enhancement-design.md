# 装备助炼、批量分解与高段强化风险设计

**日期：** 2026-07-15

**状态：** 已批准，待实施（2026-07-15 用户复核采纳 Q1–Q7 拍板；实施依据见跨计划审查 companion）

**范围：** 装备助炼、批量分解、高段强化掉级、心血结晶保护、强化上限纠偏

**不包含：** 本文不实施代码、配置、存档迁移或界面；后续由 Claude Code 按独立实施计划执行。

## 1. 背景与目标

现有系统已经具备单件出售、单件分解、按品阶批量出售和材料强化，但存在四个缺口：

1. 重复装备和普通废弃装备除了出售、分解外，没有参与核心养成的用途。
2. 批量整理界面没有批量分解入口，也缺少“每种装备至少保留一件”的默认安全线。
3. 心血结晶当前直接保证强化成功，与普通成功率系统割裂。
4. 高段强化长期停留在固定 30% 成功率且永不掉级，装备助炼在后期也缺少递减压力。

本设计建立三个职责清晰的资源轴：

- 基础材料支付每次强化尝试。
- 助炼装备提高成功率。
- 心血结晶只保护失败不掉级，不提高成功率。

同时保留装备分解的现有材料产出，不新增货币、体力、每日次数或抽卡式保底计数。

## 2. 红线决策史

### 2.1 推翻“强化永不掉级”

`GDD.md` §2.1、§6.2 与 `CLAUDE.md` §5.1 当前仍把“强化不会破防降级”列为红线。本次用户明确拍板推翻，改为：

- 冲击 +20 起，未使用心血结晶保护的失败会随机掉级。
- 心血结晶从“直接成功”改为“失败不掉级”。
- +17 是实际可达下限（+11～+19 不掉级，+20 起失败最多回落至 +17；原表述「+10 永久底线」在合法流中不可达，详 §8）；+20、+30、+40 不设阶段保底。

Claude 实施时必须在同一批同步修改 `GDD.md`、`CLAUDE.md` 和 `AGENTS.md`（三处均记录日期、原因和新规则；`AGENTS.md` 反主流红线此前还 stale 列着「装备分解」，2026-06-26 已推翻，一并订正），避免后续维护者依据旧红线将功能误改回去。

### 2.2 延续既有红线

- 不新增每日刷新、体力、登录奖励、付费保护或失败补偿弹窗。
- 境界、装备阶与心法阶的一一对应保持不变。
- 数值全部来自 YAML，Dart 不散写数值常量。
- UI 文案全部进入 `UiStrings` 或既有集中格式化层。
- 装备分解继续沿用 2026-06-26 已拍板的红线推翻记录。

## 3. 方案比较与选择

### 方案 A：成功率助炼（采用）

重复装备或同部位废弃装备提供一次强化成功率加成。优点是直接回应“多余装备有什么用”，与现有强化面板和材料经济衔接最短；缺点是高段概率与资源消耗必须清楚展示。

### 方案 B：装备经验喂养（不采用）

把废弃装备转为装备经验，再由经验提升强化等级。过程稳定，但会建立第二套强化经验账，弱化现有磨剑石、锻材与成功率体系。

### 方案 C：阶段突破必须消耗同名装备（不采用）

在 +10、+20 等节点强制消耗同名装备。目标明确，但容易卡住稀有装备并接近重复掉落门槛，不符合当前买断制的克制方向。

## 4. 强化上限纠偏

强化等级仍最高为 +49，但上限来源按装备状态区分：

- 已装备：上限等于实际穿戴者的绝对境界层数。
- 仓库装备：上限等于当前门派可编成人员中的最高绝对境界层数。出战成员和替补都计入；被百草岭远征或断魂庄占用的角色仍计入（占用不改变其可编成身份，Q7 拍板）；已飞升退隐角色不计入。
- 实际上限取上述结果与 49 的较小值。

旧存档中已经超过当前上限的装备不降级、不改属性、不迁移数据，但在门派境界重新追平前不能继续强化。界面显示“已超过当前强化上限，现有等级保留”。

## 5. 基础强化成功率

下文所有“等级”均指**本次成功后将到达的目标强化等级**，不是强化前的当前等级。

| 目标等级 | 基础成功率 | 失败是否掉级 |
|---|---:|---|
| +1～+10 | 100% | 否 |
| +11～+13 | 90% | 否 |
| +14～+16 | 75% | 否 |
| +17～+19 | 50% | 否 |
| +20～+39 | `69% - 目标等级` | 是，未保护时随机掉级 |
| +40～+49 | 30% | 是，未保护时随机掉级 |

因此 +20 为 49%，随后每级下降 1 个百分点，+39 为 30%。+40～+49 的基础成功率保持 30%。旧的“+20 起每级下降 2%，+29 后固定 30%”公式退役。

所有正常强化尝试都在事务开始后一次性扣除完整基础材料。旧的 +11～+13 失败只扣一半磨剑石规则退役。

## 6. 助炼装备

### 6.1 开放范围与两种模式

助炼从冲击 +11 开放。一次强化只能选择以下一种模式，不能混用：

1. **同名助炼：** 消耗 1 件与目标装备 `defId` 完全相同的装备，提供 +25 个百分点。
2. **废弃装备助炼：** 最多选择 3 件普通废弃装备，必须与目标装备同部位、品阶不高于目标装备，且 `defId` 不同。

废弃装备的单件加成为：

| 与目标装备的品阶关系 | 单件加成 |
|---|---:|
| 同阶 | +10 个百分点 |
| 低一阶 | +6 个百分点 |
| 低两阶及以上 | +3 个百分点 |

一次强化的助炼名义加成最多为 25 个百分点。选择结果超过 25 时按 25 计算，界面必须预览有效加成，不能只显示材料名义总和。

### 6.2 候选资格

助炼材料必须同时满足：

- 强化等级为 +0。
- 未开锋、无任何已选择开锋词条。
- `battleCount == 0`，没有共鸣成长。
- 没有实例后来获得的个人典故、传承链路或前主人记录。装备定义自带的共享 `presetLoreIds` 不影响资格；当前 80 种装备定义均有这类通用器物志，若将其视为个人履历会导致助炼候选恒为空。
- 不在任何角色装备槽，不属于当前出战编成装备。
- 不属于师承遗物、剧情或特殊来源装备。
- 未被玩家锁定，当前位于自由仓库。
- 不是本次正在强化的目标装备，也没有被另一笔事务先行消费。

同名装备按 `defId` 判断，不比较随机生成的基础属性。被培养过的装备不能作为助炼材料，避免玩家误吞长期养成资产。

### 6.3 消耗规则

- 助炼装备在玩家确认并通过事务内最终校验后全部删除。
- 无论强化成功或失败，助炼装备都不返还。
- 助炼与心血结晶保护允许同时使用。
- 冲击 +49 时助炼无法提供任何有效增益，界面直接禁用助炼区，服务层也拒绝附带助炼装备的 +49 请求。

## 7. 助炼后的成功率上限

最终成功率按以下顺序计算：

1. 读取目标等级的基础成功率。
2. 加上本次有效助炼加成。
3. 截断到目标等级对应的助炼成功率上限。

冲击 +11～+39 的通用上限为 95%。在 +20～+39，由于基础成功率和最大助炼加成之和本身低于 95%，满额助炼结果自然从 +20 的 74% 每级下降 1 个百分点，到 +39 的 55%。

冲击 +40～+49 时，助炼成功率上限按下表线性下降：

| 目标等级 | 助炼后最高成功率 |
|---:|---:|
| +40 | 52.5% |
| +41 | 50% |
| +42 | 47.5% |
| +43 | 45% |
| +44 | 42.5% |
| +45 | 40% |
| +46 | 37.5% |
| +47 | 35% |
| +48 | 32.5% |
| +49 | 30% |

等价公式为：

```text
max(30%, 52.5% - 2.5% × (目标等级 - 40))
```

## 8. 随机掉级

未使用心血结晶保护时，失败掉级范围按目标等级决定：

| 目标等级 | 失败掉级范围 | 分布 |
|---|---:|---|
| +11～+19 | 不掉级 | — |
| +20～+29 | 随机掉 1～2 级 | 各结果等概率 |
| +30～+39 | 随机掉 1～3 级 | 各结果等概率 |
| +40～+49 | 随机掉 1～4 级 | 各结果等概率 |

失败后的等级为：

```text
max(17, 当前强化等级 - 随机掉级数)
```

**+17 是实际可达下限**（2026-07-15 订正，取代原 +10）。状态演算：掉级只发生在冲击 +20～+49（+11～+19 段不掉级），失败时「当前强化等级」必为「目标等级 − 1」，最低即冲 +20 时的 +19；+20～+29 段最多掉 2 级，故 +19 冲 +20 失败最多回落到 **+17**。此后冲击 +18／+19（落回 +11～+19 段）不再掉级，装备停在 +17，无法继续下探。因此原 +10 永久底线在合法状态流中不可达，真实下限为 +17。已经到达 +20、+30 或 +40 不会形成永久检查点，连续未保护失败可以跨阶段下降，但永远不会低于 +17。

## 9. 心血结晶保护

心血结晶不再直接保证成功，也不改变成功率。保护只在冲击 +20～+49 时开放。

本次保护消耗为：

```text
心血结晶数量 = 目标强化等级 - 17
```

例如冲击 +20 消耗 3 个、+30 消耗 13 个、+40 消耗 23 个、+49 消耗 32 个。每提高一级，消耗严格增加 1 个。

结算规则：

- 选择保护后，结晶在尝试开始时与其他资源一并扣除，成功或失败都不返还。
- 成功时正常提升 1 级。
- 失败时维持当前等级，不执行随机掉级。
- 保护强化无论成败都不产出心血结晶。
- 未使用保护且强化失败时获得 1 个心血结晶。
- 助炼与结晶保护可以同时使用，各自只承担自己的职责。

## 10. 开锋词条休眠

强化失败可能使装备跌破 +10、+15 或 +19 的开锋门槛。处理规则为：

- 已选择的开锋词条、专属技能和槽位记录永久保留，不删除、不重洗。
- 当前强化等级低于某槽门槛时，该槽进入“休眠”，属性和专属技能不参与战斗计算。
- 重新强化回对应门槛后，原词条自动恢复生效，不再次消耗开锋辅材。
- 详情页显示“词条已保留，强化至 +X 后重新生效”。

实现上保留既有开锋数据结构；是否生效由当前强化等级与 YAML 中的 `unlock_at_enhance_level` 动态派生，不新增存档字段。

## 11. 分解与批量整理

### 11.1 单件分解

单件出售和分解保持现状。分解继续按当前品阶和强化等级产出磨剑石与心血结晶：

- 不新增货币。
- 不产出锻材。
- 不修改现有七阶基础产出和强化等级返还公式。
- 已装备、锁定、师承遗物、高阶、剧情/特殊来源、带个人典故或传承履历的装备继续受保护。

### 11.2 批量分解

现有整理界面在“一键出售”旁增加“一键分解”。两者共用安全候选列表和确认预览，但执行各自独立的原子事务。

默认启用“每种装备至少保留 1 件”：

- “每种”按 `defId` 计算。
- 已装备、锁定或其他受保护的同 `defId` 装备也算作已经保留，因此不需要额外保留一件自由装备。
- 如果该 `defId` 只有自由、可处置装备，则默认保留一件，其余进入候选。
- 默认保留件按以下顺序确定：强化等级更高、已开锋槽更多、`battleCount` 更高、基础三项属性总和更高、获得时间更早、实例 id 更小。该顺序只用于稳定选择，不改变装备数值。
- 玩家可以在明细中取消某件处置，但不能强行包含受保护装备。

确认页显示：装备名称、实例强化等级、处置数量、逐类排除原因和总收益。批量分解继续调用服务层重新校验；确认页打开后若装备状态变化，整批取消并刷新，不做部分成功。

## 12. 强化界面

强化面板必须同时展示：

- 当前等级、目标等级与强化上限来源。
- 基础成功率、助炼有效加成、目标等级上限和最终成功率。
- 基础材料、助炼装备、心血结晶的本次消耗及当前库存。
- 未保护失败时的随机掉级范围。
- 使用保护后的失败结果“维持当前等级”。
- 所选助炼装备逐件明细，以及“无论成败均会消耗”的醒目说明。

交互规则：

- 同名助炼和废弃装备助炼使用互斥选择器。
- 不合资格的装备不进入候选，而不是显示后允许点击。
- +11～+19 选择助炼装备时，提交前显示消耗确认。
- +20～+49 每次提交都显示资源与风险确认，无论是否使用助炼或结晶。
- +49 助炼区禁用并说明“助炼上限已降至基础 30%”。
- 确认后若事务校验失败，界面刷新库存和装备状态并显示集中化错误文案。

## 13. 架构与原子结算

规则划分为三个可独立测试的纯模块：

1. **成功率规则：** 基础曲线、助炼加成、目标等级上限。
2. **助炼资格规则：** 分类候选、保护状态、履历和培养状态校验。
3. **失败等级规则：** 目标等级对应的随机区间、+17 底线和保护结果。

强化服务是唯一写入口。一次尝试必须在同一原子事务内完成：

1. 重新读取目标装备、角色/门派强化上限、材料库存和助炼装备。
2. 校验目标等级、资源、助炼模式、候选资格和 +49 禁用规则。
3. 扣除完整基础材料、全部助炼装备和可选心血结晶。
4. 使用可注入随机源判定成功或失败；未保护失败再抽取等概率掉级数。
5. 更新强化等级、开锋生效状态的派生结果和未保护失败的结晶产出。
6. 一次性提交全部变化。

任一步校验或写入失败都必须回滚，不能出现扣材料但未结算、重复吞装备或部分批量分解。

建议服务返回可区分的领域结果：材料不足、结晶不足、助炼装备不存在、助炼资格失效、模式混用、超过强化上限、+49 禁止助炼、事务冲突和成功/失败结算。表现层只负责把领域结果映射到 `UiStrings`。

## 14. 配置与存档

`data/numbers.yaml` 是所有数值的唯一来源，至少承载：

- 基础成功率区间与 +20～+39 线性公式参数。
- 助炼开放等级、两种模式的加成、件数和总加成上限。
- +40～+49 助炼成功率上限曲线。
- 三个随机掉级区间、等概率规则和 +17 底线。
- 心血结晶保护开放范围、线性消耗公式参数和失败产出。
- 开锋槽生效门槛。
- 批量整理默认保留开关。

不新增 `Equipment` 或 `SaveData` 字段，不提升存档版本。旧装备等级、开锋词条和资源库存原样读取。

## 15. 测试与验收

### 15.1 纯规则测试

- 枚举 +1～+49 的完整基础成功率表。
- 验证 +20～+39 每级下降 1 个百分点。
- 验证 +40～+49 助炼上限从 52.5% 每级下降 2.5 个百分点至 30%。
- 覆盖同名装备、三档废弃装备、最多三件和 25 个百分点总上限。
- 覆盖三个随机掉级区间的每个边界、等概率映射和 +17 底线。
- 枚举 +20～+49 的结晶消耗，验证每级严格增加 1。

### 15.2 服务测试

- 注入可控随机源，分别验证成功、失败和每个掉级端点。
- 基础材料和助炼装备无论成败都完整消耗。
- 结晶保护无论成败都消耗，失败不掉级。
- 未保护失败获得 1 个结晶；保护尝试不产出结晶。
- 助炼与结晶同时使用时各自规则互不覆盖。
- 任一校验失败时装备、等级、材料和库存全部不变。
- 重复点击、并发消费或候选状态变化不会重复扣除。
- 仓库装备与已装备物品分别读取正确的境界强化上限。

### 15.3 开锋与存档测试

- 跌破 +10、+15、+19 后对应槽休眠，回到门槛后原词条恢复。
- 休眠期间词条和专属技能不进入战斗派生属性。
- 旧存档无需迁移，原强化等级和开锋选择完整保留。
- 原本超过当前境界上限的装备保留等级但不能继续强化。
