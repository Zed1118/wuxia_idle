# 同款同位战斗特效合流计划

> 上游稳定点：`codex/battle-popup-overlap-spread@012ef668`
> 分支：`codex/battle-effect-coalescing`

## 1. 目标

AOE 隐藏敌人归并到同一后景槽时，同一次施放中相同资源、相同落点与相同参数的特效贴片只保留一个动画实例并续播，避免完全重合造成过亮、性能浪费和视觉噪声。

## 2. 方案

- `_spawnEffect` 入队前查找同施放组内的等价活跃贴片；命中则从头续播既有 controller，不创建新 entry。
- 施放组由 tick、施术者与技能共同标识，不跨 tick 或跨角色吞掉独立出手。
- 等价键包含资源、落点、尺寸、透明度、旋转与镜像，防止误合并不同表现。
- 不合并不同目标位置、不同资源或不同参数的特效；飘字与弹道保持独立。

## 3. 验收

- [x] 同一施放组内同目标的重复暴击只保留“流派 + 暴击”两个贴片实例。
- [x] 两个不同目标的相同暴击仍各自保留完整贴片。
- [x] AOE 共享反馈、特效完成移除和重启清理不回归。
- [x] 完整战斗模块、analyze 与双视口 UI 通过，冻结 `[READY]`。
