# P2-M1-C02：六几何纯领域候选

## 交付范围

- 新增 `combat_geometry.dart`，以调用方注入的参数表达前向扇形、自身圆形、目标点圆形、直线/胶囊、位移轨迹和自身状态。

## 恢复点

1. 先运行几何单测，确认六种 typed scope 的边界行为与排序稳定性。
2. G1 主审需确认公开命名、锚点语义、墙体/场地边界和 AI 选点合同，再由后续任务接入 typed binding。
3. 接生产前必须补充命中集冻结时机、预警形状、场地阻挡策略及与事件顺序的契约测试。

## 已知风险

- 本模块是候选纯领域 API，尚未接生产路径；任何生产接线都必须等待 G1 主审，避免形成第二套 reducer 或 session。
- 墙体、场地边界和 AI 选点需要由调用方提供合法候选/裁剪策略，本切片不擅自写玩法数据或地图常量。
- 命中排序当前以几何距离、再以稳定 id 破平局；若 G1 规定显式优先级字段，需在接线前扩展目标快照合同。
