# P2-M1-C09 三特性 modifier 纯领域候选

## 目标

提供可组合、确定性的 typed modifier schema：刚猛只修饰击退/姿态/破阵，灵巧只修饰追步/闪避轨迹/收招恢复，阴柔只修饰牵引/减速/内伤/控制时长。所有基础值、修饰因子和上限均由调用方注入。

## 本切片

- `lib/features/battle/domain/phase0a/combat_modifiers.dart`：三类互斥参数构造器、基础值/上限 typed 容器、按调用方顺序组合与最终上限。
- `test/features/battle/domain/phase0a/combat_modifiers_test.dart`：合法域、非法因子、跨域编译边界、组合顺序/确定性、调用方上限和负值校验。

## 验证

- `dart format lib/features/battle/domain/phase0a/combat_modifiers.dart test/features/battle/domain/phase0a/combat_modifiers_test.dart`
- `flutter analyze lib/features/battle/domain/phase0a/combat_modifiers.dart test/features/battle/domain/phase0a/combat_modifiers_test.dart`
- `flutter test --no-pub test/features/battle/domain/phase0a/combat_modifiers_test.dart`

## 恢复点与风险

- 当前切片未接生产、data、model、reducer 或武器逻辑；三特性仅表达共享参数 modifier。
- `recoveryDuration` 的因子方向、各参数最终语义及 G1 与姿态/状态 API 的绑定仍待主审确认；本候选不写玩法数值或中文文案。
- 上限只在组合末端按调用方注入的 `ModifierBounds` 截断，正式接线前需由 G1 确认各字段的红线归属。
- 主审复用现有 `TechniqueSchool.gangMeng/lingQiao/yinRou`，避免另造同义枚举；修饰因子必须为有限正数，避免零因子把恢复/控制等时长直接抹除。
