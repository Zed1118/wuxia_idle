# 快进态战斗演出密度计划

> 上游稳定点：`codex/battle-rhythm-audit@ae54c6ec`
> 分支：`codex/battle-fast-forward-vfx-density`

## 1. 目标

快进/扫荡以 100ms 一次行动推进时，避免 520ms 特效贴片、260ms 弹道和逐击音效跨多拍堆积；常速与首通可读节奏保持原演出时长和声音反馈。

## 2. 方案

- 新生成的贴片与弹道时长 clamp 到当前播放拍长，沿用伤害飘字“不过拍”原则。
- 快进态不逐击播放 SFX，避免每秒十次以上音频池叠播；常速不变。
- 不碰结算、动作日志、随机数、伤害、技能或胜负。

## 3. 验收

- [x] 快进态连续多动作产生的贴片与弹道在一个拍长后归零。
- [x] 常速仍保留逐击 SFX，快进态抑制逐击 SFX。
- [x] 常速特效 520ms 生命周期与同组续播契约不回归。
- [x] 战斗模块、analyze 与双视口 UI 通过，冻结 `[READY]`。
