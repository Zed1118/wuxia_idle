# 唯一合法目标即放计划

> 上游稳定点：`codex/battle-aoe-kill-feedback@6ed7568e`
> 分支：`codex/battle-single-legal-target`

## 1. 目标

单体技能的“一敌即放 / 多敌选目标”分流必须按合法目标数判断，而不是按仍存活的敌人数判断；护法结界等门控后只剩一个可选目标时，点击技能应直接出手。

## 2. 方案

- `_onSkillTap` 复用 `canManuallyTargetEnemy` 先生成合法目标列表。
- 0 个合法目标不进入待发；1 个合法目标立即指定并出手；2 个以上才软暂停进入目标选择。
- 破招技面对蓄力中的受保护 Boss 仍沿现有例外进入合法目标集。
- 目标 chip 与战场提示继续复用同一合法性函数，保持 UI/strategy 单一口径。

## 3. 验收

- [x] Boss + 存活护法且其他敌人阵亡：普通单体技直接命中护法，不出现待发栏。
- [x] 两个以上合法目标仍进入待发并显示对应 chips。
- [x] 无合法目标不下发、不暂停。
- [x] 1280×720 与 1440×900 UI 回归通过。
