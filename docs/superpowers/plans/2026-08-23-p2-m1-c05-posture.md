# P2-M1-C05 姿态纯领域候选

## 目标

以纯 Dart 候选模块表达 M1 姿态合同：姿态伤害从零累计至调用方注入的容量；达到阈值进入配置化破绽；破绽结束按配置重置或恢复到指定累计值；霸体仍承受姿态累计但轻击不产生打断；Boss 控制强度通过调用方注入折算因子转换为姿态伤害。

## 本切片

- `lib/features/battle/domain/phase0a/posture.dart`：不可变配置、状态、转移事件与 Boss 控制折算纯函数。
- `test/features/battle/domain/phase0a/posture_test.dart`：非法容量、阈值边界、超量截断/事件、霸体轻击、破绽期间、重置/恢复和确定性测试。

## 验证

- `dart format lib/features/battle/domain/phase0a/posture.dart test/features/battle/domain/phase0a/posture_test.dart`
- `flutter test --no-pub test/features/battle/domain/phase0a/posture_test.dart`

## 恢复点与风险

- 当前切片**未接生产路径**，没有修改 `phase0a_combat_model.dart`、`phase0a_combat_reducer.dart`、数据配置或任何生产入口。
- `posture.dart` 是 M1 领域 API 候选，事件命名、破绽时间单位、恢复目标语义及 Boss 控制折算接口仍待 G1 主审；主审前不得据此批量改内容或接 reducer。
- 破绽期间姿态伤害被抑制且不重复触发；这是本候选的安全默认行为，正式接线前需由 G1 确认。
