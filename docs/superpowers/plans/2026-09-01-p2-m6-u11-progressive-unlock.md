# P2-M6-U11 渐进解锁与一次性蜡封结果合同

- 唯一目标：把七项现有生产入口统一投影为 `hidden / heard / open`，并用可恢复的一次性蜡封记录真实由非开放推进到开放的事实。
- 固定验收门：`0/1 → 1/1`，分母是“生产入口三态 + durable 一次性确认”这一条完整工程门。
- 实时基线：七入口各自直接读取 bool、锁定状态或不渲染；没有共享三态，也没有可跨重启防重复的已展示事实。
- 关键阻塞：只做内存红点会在重启后重复或丢失；只在主菜单首帧观察会漏掉页面保持挂载期间发生的解锁。
- 成本上限：保持一个主 WIP，至 2026-09-01 08:00 前完成 targeted、破坏证红、整仓验证、Gate、合并推送和精确 SHA CI；无验收门增量时停止扩张。
