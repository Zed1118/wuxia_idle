# P2-M1-C04 防御解析纯领域候选

## 目标

以纯 Dart 候选冻结五个正交攻击 flags：`blockable`、`parryable`、`reflectable`、`dodgeable`、`interruptible`；按闪避 → 化解/重定向 → 护盾/格挡 → 基础减伤 → HP/姿态 → 反击的单分支顺序解析入站攻击。

## 本切片

- `lib/features/battle/domain/phase0a/defense_resolution.dart`：flags 校验、注入式伤害/减伤输入、确定性解析结果，以及非递归反击/重定向安全标记。
- `test/features/battle/domain/phase0a/defense_resolution_test.dart`：flags 正交性、反射与反击分离、分支优先级、护盾/格挡/基础减伤顺序、Boss 高伤不复制、非法负值、上限/整数边界和确定性测试。

## 验证

- `dart format lib/features/battle/domain/phase0a/defense_resolution.dart test/features/battle/domain/phase0a/defense_resolution_test.dart`
- `flutter analyze lib/features/battle/domain/phase0a/defense_resolution.dart test/features/battle/domain/phase0a/defense_resolution_test.dart`
- `flutter test --no-pub test/features/battle/domain/phase0a/defense_resolution_test.dart`

## 恢复点与风险

- 当前切片**未接生产路径**，没有修改 model、reducer、数据配置、UI 或生产入口。
- `defense_resolution.dart` 是 M1 typed API 候选；字段命名、护盾与格挡的组合语义、减伤乘区及反击上限仍待 G1 主审，主审前不得接入 reducer 或批量填数值。
- 反击与重定向结果固定 `nonRecursive=true`，并默认禁止暴击、吸血和受击后反伤；如未来需要例外，必须由 typed allowlist 与独立上限测试显式授权。
- 复核修正：移除 `parryable -> blockable` 的错误耦合，flags 保持正交；算术溢出在结果层钳到 `double.maxFinite`，避免无穷伤害泄漏。
