## 源任务

### R01：规则与配置迁移（Pi + DeepSeek V4 Flash）

1. 删除 `failure_penalty.main_cultivation_multiplier` 的生产配置与类型入口。
2. 对退役键提供显式拒绝，防止旧惩罚静默回归。
3. 心魔失败只应用受上限约束的内息紊乱；主修修炼度、境界、永久内力、装备和伤势均不变。
4. 保留结果快照中的前后值证据，但不得写回修炼度。
5. 用定向测试覆盖非整值进度、上限、重复失败和旧配置拒绝。

### R02：战败摘要对齐（Qoder CLI + Qwen3.8-Max）

1. 心魔战败摘要显示心魔名与“内息紊乱”。

3. 普通 Boss 战败的伤势、内力和修炼度摘要保持不变。
4. 只有确认无调用后才删除退役字符串。
