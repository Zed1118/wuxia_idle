# Phase 2 M5 轻功自动准入结果合同

- 单一目标：轻功已首通路线通过 typed request 进入真实 bot/headless/差遣 runner，并复用 exact participant、共享 Phase 0A 与结算。
- 固定验收门：`0/1 → 1/1`；typed admission、真实 production runner 与共享 settlement 必须同链成立。
- 重资格化基线：塔门证明既有 `Phase0aSweepHeadlessRunner` 可以通过新增模式专用 application 方法复用同一 mapper/assembler/headless 内核；`Phase0aStageContentMapper.mapLightFoot` 也已存在，因此即时 headless 的执行技术路径可行。
- 当前关键阻塞：本门固定分母同时要求前台 bot、快速 headless 与差遣。轻功没有玩家可达自动入口，也没有 durable run/session；`ActivityKind` 与 `CharacterOccupancyService` 只表达闭关、百草岭和断魂庄，无法在不改 schema/共享占用真相源的情况下表示轻功差遣、锁装、离线推进和返程报告。
- 成本：90 分钟停止线；本门只做只读 owner 审计与轻功域回归。
- 非目标：新 reducer/session/headless 内核/provider/settlement 真相源、schema/saveVersion、YAML、TUNING、奖励、经济、解锁、叙事、战斗规则或 main。

## 结果

- 验收门保持 `0/1 BLOCKED`。只实现即时 headless 或孤立 allowlist 无法关闭固定门，故本次不制造部分生产代码。
- 轻功域 `12/12 PASS`，只证明当前手动逐次选人和三态进度未回归。
- 解阻授权：需要选择并授权轻功差遣的 durable owner（扩展既有活动 session/occupancy，或明确取消本门的差遣分母）；前者必然触及 schema/saveVersion/共享占用真相源，当前红线禁止猜测。
