# 护法结界手动目标门控计划

> 上游稳定点：`codex/battle-pending-focus-lock@73b5d7c1`
> 分支：`codex/battle-pending-target-validity`

## 1. 目标

让手动点选与自动选敌共用护法结界目标规则：护法存活时普通单体技不能绕过结界直点 Boss；破招对蓄力 Boss 的既有防御例外保持不变。

## 2. 方案

- 在 domain 提供单一的手动目标资格判断：存活、非受护法保护，或“破招技 + 目标正在蓄力”。
- 目标快捷签与战场头像共用资格集合，不展示/高亮不可选 Boss。
- `interveneNow` 在策略边界拒绝不可选指定目标，防止绕过 UI 或静默改打其他人。
- 不改护法减伤数值、自动 AI、AOE 与破招锁定规则。

## 3. 验收

- [x] 护法存活：普通单体技目标栏排除受保护 Boss、保留护法。
- [x] 伪造指定受保护 Boss：策略 noop，不消耗 AP / 真气。
- [x] 破招技面对正在蓄力的受保护 Boss：保持可用。
- [x] 护法阵亡：Boss 恢复手动可选。
- [x] 相关测试、完整战斗模块、analyze 与双视口通过。
