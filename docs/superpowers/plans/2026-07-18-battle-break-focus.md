# 破绽窗口可操作焦点计划

> 上游稳定点：`codex/battle-actionable-burst-prompt@a32a6e9a`
> 分支：`codex/battle-break-focus`

## 1. 目标

破绽提示出现时，让武学案台确实展示可立即下发招式的角色；但若玩家当前重点角色已可操作，不改变其手选焦点。

## 2. 方案

- 敌人蓄力时的可破招者焦点优先级保持最高。
- 敌方有存活破绽目标时：先检查手选角色是否有可下发非普攻招式；有则保留，无则临时切到队内首个可操作角色。
- 临时焦点不改写 `_focusSlotIndex`，破绽结束后回到玩家手选基线。
- 不代玩家出手，不改 AP、真气、CD、AI 与结算。

## 3. 验收

- [x] 破绽存在且当前焦点不可操作：案台临时切到可爆发队友。
- [x] 当前焦点已可操作：保留玩家手选角色。
- [x] 破绽结束：回到手选基线。
- [x] 蓄力破招焦点优先级不回归。
