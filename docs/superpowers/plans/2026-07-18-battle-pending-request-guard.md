# 延后手动请求合法性计划

> 上游稳定点：`codex/battle-single-legal-target@650f65cb`
> 分支：`codex/battle-pending-request-guard`

## 1. 目标

保留给重放/兼容路径的 `requestUltimate` 不能成为绕过即时干预防线的后门：只能为存活的玩家角色排入其已装备的规范技能，并且指定目标必须符合当前手动目标规则。

## 2. 方案

- 保持普攻请求抛 `ArgumentError` 的旧接口契约。
- 战斗结束、角色不存在/阵亡/非玩家方、技能未装备时返回原状态。
- 按 skill id 找到角色快照中的规范 `SkillDef` 并写入 pending，拒绝调用方伪造倍率或类型字段。
- 单体指定目标复用 `canManuallyTargetEnemy`；AOE 不写无意义的 `pendingTargets`。
- 不新增资源/CD 门控：延后语义仍允许提前排入，由行动时 `_canUse` 决定是否消费。
