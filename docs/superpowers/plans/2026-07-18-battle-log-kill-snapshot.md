# 击杀战报动作快照计划

> 上游稳定点：`codex/battle-report-aoe-dedupe@36e53c39`
> 分支：`codex/battle-log-kill-snapshot`

## 1. 目标

“击杀”必须描述动作发生当刻，而不是读取当前角色存活状态；敌人后来阵亡不能把早先普通命中追溯成击杀战报。

## 2. 方案

- `BattleAction` 增加默认 false 的击杀快照字段。
- 单目标结算在 HP 从存活降至 0 时写入 true，AOE 每个目标独立记录。
- 完整日志、紧凑战报、关键动作筛选和 AOE 代表评分统一读取动作字段。
- 战斗结算的最终阵亡总结仍读取最终队伍状态，不改变。
