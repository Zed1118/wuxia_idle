# Phase 0A Batch 8B：战斗反馈强化

**日期**：2026-08-17  
**基线**：`main@be258fcb`  
**分支**：`codex/phase0a-batch8b-combat-feedback`

## 目标

在不改变伤害、范围、CD、真气与敌人行为的前提下，提升 Phase 0A 正式可玩战斗的命中辨识与释放感，继续消除“原始图形 Demo”观感。

## 冻结范围

1. 命中反馈：角色短闪白，敌方血条受击后保持强调；玩家受击同步强调 HUD 气血。
2. 攻击分型：近距离命中使用双弧墨痕，远距离命中保留掌风但升级为有体积的青墨掌风片。
3. Q 聚怪：每个 pulled 目标携带事件时的位置快照，绘制目标指向玩家的拉拢轨迹。
4. 死亡层级：普通敌人使用克制墨散，精英使用更大范围、双层墨环与绛红点染。

## 设计方向

- 主色只用既有 `WuxiaUi.ink/qing/jiang/paper`，不引入 Material 默认高饱和色。
- 特效轮廓保持不完全对称、干湿墨并存；不使用白色直线、标准圆环或规则 X 作为主视觉。
- 角色、名字、血条优先可读；特效不遮挡 HUD 与技能印。
- 所有持续时间、尺寸、线宽进入 `Phase0aPresentationTokens`，不得散写。

## 禁止项

- 不改 domain/reducer 战斗规则或 `numbers.yaml`。
- 不接音效，不新增无资产 `SfxId`。
- 不做重试入口、键盘导航、镜头震动、hit-stop。
- 不修改旧 3v3 战斗、存档、奖励、正式生产路由。
- 不新增图片、第三方依赖或 Flame 生产依赖。

## 实现契约

- `Phase0aVfxController` 只搬运事件结果；近战/远程分型只使用既有距离阈值，不重算伤害。
- `gatherPull` 必须保存 target→actor 的 `source/vfxTarget` 快照，渲染时不得反查移动后的 state。
- 命中闪白与血条强调由 screen 的短时表现状态驱动，不写回 `Phase0aActor`。
- 死亡目标即使已从 state 移除，仍使用 Batch 8A 的事件位置快照。

- widget 测试覆盖命中闪白出现/消失、血条强调保持/消失、近远程 VFX 分型和 Q 轨迹坐标。
- 既有 Batch 8A 坐标、容量、终局与技能印测试不得回归。
