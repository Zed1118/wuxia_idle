# 群攻击杀共享反馈计划

> 上游稳定点：`codex/battle-variant-intervention@7ed453a0`
> 分支：`codex/battle-aoe-kill-feedback`

## 1. 目标

一次群攻只播放一套共享演出的前提下，只要任一目标被击杀，本次施放仍必须获得一次击杀特写与关键顿帧；不能因共享代表动作恰好选中另一目标而漏反馈。

## 2. 根因与方案

- 群攻逐目标动作中只有代表动作进入共享题字/震屏/顿帧/特写分支。
- 代表选择重视暴击、破绽、弱点、破招，但“本次施放是否有人阵亡”是施放级事实，不应与这些代表特征互相抢占。
- 分组时汇总 `cast.any(defeatedTarget)`，仅透传给代表动作的共享反馈。
- 关键顿帧与击杀特写读取该施放级标志；逐目标飘字和受击反馈保持不变，绝不重复特写。

- [x] 无击杀群攻不误触发特写。
