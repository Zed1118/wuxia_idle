# 群战同槽飘字散开计划

> 上游稳定点：`codex/battle-hitstop-beat-freeze@40303c65`
> 分支：`codex/battle-popup-overlap-spread`

## 1. 目标

群战第 4–7 名敌人归并到后景表现槽、或同一可见角色短时间承受多段伤害时，伤害飘字不应完全重叠；暴击保留首条中央爆发，其余条目向四角稳定散开。

## 2. 方案

- 普通/闪避飘字按当前槽内活跃条目数轮转四角，不再重复叠加全局 ID。
- 同槽第一条暴击使用 `centerBurst`，已有中央暴击时后续暴击进入四角轮转。
- 仅调整表现锚点，不改动作数量、伤害、播放间隔或群攻代表动作。
