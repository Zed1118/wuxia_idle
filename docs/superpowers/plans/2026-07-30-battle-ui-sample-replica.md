# 战斗界面样板复刻计划

> 日期：2026-07-30  
> 分支：`codex/battle-ui-sample-replica`  
> 唯一视觉基线：`docs/spec/battle_ui_stage_command_desk_v2_2026-07-15.png`

## 目标

在不修改战斗规则、数值、存档和数据 schema 的前提下，让生产 `BattleScreen`
重新贴近 2026-07-15 样板：人物为第一视觉主体、战景为第二主体，顶栏与脚下状态
只作辅助，底部恢复写实旧纸技能签和木匣行囊的控制密度。

## 验收标准

- [ ] 生产接线：修改由真实 `BattleScreen`、`CharacterAvatar`、`BottomBar` 消费，
      不停在 fixture 或孤立组件。
- [ ] 结构：1280×720 / 1440×900 保持顶栏约 6.5%、战场约 68.5%、案台约 25%。
- [ ] 顶栏：控制恢复为紧凑章钮，不再读成现代矩形工具栏；保留 tooltip、
      semantics、键盘/鼠标语义。
- [ ] 人物：脚下状态板收束为透明窄条，不遮人物、不抢背景；人物融合按场景明度自适应。
- [ ] 案台：七个稳定技能位保持，空位不形成大面积亮色“空表单”；行囊不展示虚假道具状态。
- [ ] Targeted tests：战斗指令台、顶栏、人物状态、立绘融合相关测试通过。
- [ ] 静态检查：`flutter analyze --no-pub` 0 issue。
- [ ] 视觉 smoke：标准 3v3 在 1280×720 / 1440×900 完整复拍，零 overflow/exception。
- [ ] 红线：不改伤害、血量、真气、技能、AI、在线离线逻辑；不新增中文 Dart 文案；
      不引入 Material 饱和色；不改 schema/saveVersion。
- [ ] 残留风险如实记录：不同关卡素材风格差、Windows 字体/缩放未实机目检、
      动态峰值帧未覆盖。

6. Targeted tests + analyze。
7. 双视口完整复拍与样板逐项评分。
