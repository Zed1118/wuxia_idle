## 冻结项

- 视觉路由：`battle_tap_live`
- 战斗 RNG seed：`20260719`
- fixture label：`visual-route-host-fixture-20260627`
- 窗口：`1280×720`
- 时长：45–60 秒
- 阵容：祖师 / 弟子·凌风 / 弟子·云舟 vs 隐世老者 / 山贼刀客 / 山贼弓手
- 场景：山道伏击

该路由渲染正式 `BattleScreen`，手动指令最终走
`BattleNotifier.interveneNow -> BattleStrategy.interveneNow`。队伍是内存 fixture，
不进正式关卡、掉落、结算或存档。

## 安全边界

1. 只从 Phase 0A 工作树对应 commit 构建。
2. 视觉路由的 Isar 位于 `Directory.systemTemp/wuxia_idle_visual_routes`，每次启动先删除再重建。
3. 不得从落后且未包含 Isar 隔离修复的 checkout 启动。
4. 对照 app 与其他视觉路由串行使用；不并发启动两个视觉路由进程。

## 测试者操作

1. 打开后保持暂停，使用顶栏“单步”推进，不点“继续”。
2. 单步到“断流”可用，点“断流”，再点“隐世老者”头像。
3. 继续单步到“踏雪”冷却完成，单点“踏雪”。
4. 自由单步和点选其他技能，到 45–60 秒时停止。

> 主持人只说明“使用单步推进，不点继续”，不讲解最优技能顺序。
