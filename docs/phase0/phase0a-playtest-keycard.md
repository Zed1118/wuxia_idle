# 《挂机武侠》Phase 0A 键位卡

目标：独自完成三轮围攻。请先自行尝试，不需要寻找队友或换人功能。

正式测试由观察员使用包内 `主持试玩.command` 选择 P01–P06；工具会按
冻结的 AB/BA 顺序串行打开“当前点招对照”和“Phase 0A 灰盒”。
请勿手动直开两个 app，也不要同时运行它们。

| 操作 | 键位 |
|---|---|
| 移动 | `WASD` / 方向键 |
| 瞄准 | 鼠标 |
| 普攻 | 鼠标左键 |
| 身法 | `Space` |
| 聚怪 | `Q` |
| 清场 | `R` |
| 暂停 | `Esc` |

结束后请停留在结算画面，先回答观察员的问题，再决定是否点击“再打一轮”。
