## 结构化存档与裁决

1. 复制包内 `问卷模板.json` 到当前 Pxx 会话目录，固定命名为
   `human-session.json`；只写匿名编号，不写姓名、账号、邮箱或电话。
2. 评分、二元问题、三种动作职责、5 帧判断、完整性与直接否决项全部填写；
   未填完的样本必须保持 `valid=false` 并写明 `invalid_reasons`。
3. 六人完成后由观察员在包根目录运行：

   ```zsh
   ./phase0a_human_gate human results/sessions results/human-gate-summary.json
   ```

汇总器只会输出 `HUMAN_GATE_PASS` / `LOCAL_FAIL` / `INCONCLUSIVE`；
它不会把不足 6 人、混包、问卷缺失或外部污染自动算成通过，也不代签
Mac、隔离或 Windows Gate。
