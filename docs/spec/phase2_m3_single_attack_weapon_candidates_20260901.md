## 边界

- 本文是 `TUNING/candidate`，不是生产数值决定；对应值只存在于 `test/tuning/phase2_m3_single_attack_weapon_candidates_test.dart`。
- 未修改 `data/numbers.yaml`、装备基础属性、玩家属性、技能、真气、奖励、经济或存档。
- 五类候选都保持：单段、可按住持续请求、攻击位移 `0`、每次普攻最多命中 `1` 个目标；不恢复三段链、追步、进步斩、shield/parry 或 `Z`。

## 选型风险与下一步

- 软兵当前清杂恰好到候选上限 `12.0s`，Boss 也最慢。若真人感到拖沓，优先在伤害/冷却二选一微调，不能靠拉扯玩家或恢复多段链补强。
- 双持 Boss 需要 `45` 次出手，频率身份最强，但也最容易放大生产普攻产气。正式值进入生产前必须用真实 `qiDelta` 重跑资源红线，不能把本测试的 `+1/次` 当正式真气值。
- 重兵最宽但仍只命中一个目标；真人若只感到“慢”而感受不到重量，需要先补表现层冲击、音色和墨迹宽度，不应直接用多目标或更高伤害掩盖。
- 暗器与软兵都偏远程，区别依赖“窄直精确”与“长弧控距”的可见表现，必须留到真实桌面目检判断。
- 本表保留为选型溯源，不再作为当前待决项；正式画像必须以 production catalog、真实 45 格矩阵和后续真人桌面复验为准。
