## 三、批量替换的避坑写法(重要)

1. **不要用 `sed -i`**。macOS 的 BSD sed `-i` 语义不同且对 UTF-8 不稳。**统一用 `perl -CSD -i -pe`**(`-CSD` 强制 UTF-8 读写,不加会把中文变成 `?`)。
2. **分隔符用 `{}`**:`s{旧}{新}g`。路径含 `/`、md 表格含 `|`,这两个都不能当分隔符。
3. **pattern 用 `\Q...\E` 包住**:`s{\Qlib/ui/strings.dart\E}{lib/shared/strings.dart}g`。否则 `.` 会匹配任意字符(`main_menu.dart` 会误配 `main_menuXdart`)。
4. **长路径优先**:`lib/ui/` 是 `lib/ui/theme/` 的前缀。裸替 `lib/ui/` → `lib/shared/` 会把 `lib/ui/battle/` 错成 `lib/shared/battle/`(应为 `lib/features/battle/presentation/`)。**本单量小(21 处),建议逐条精确替换,不要写通配规则。**
5. **不要按表格列解析再拼回**(`awk -F'|'`)——会吃掉行内合法的 `a|b` 内容。要改就对整行做替换。
