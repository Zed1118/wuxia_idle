## 一、任务背景(自包含,执行端无本方上下文)

本仓是 Flutter 写实武侠挂机游戏,核心设计红线之一是 **§5.6 不硬编码**:所有可调数值/概率/门槛必须从 `data/*.yaml` 配置读取,Dart 代码里不得写死。

已有两轮审计做过相邻但**不同**的事,本单不要重复:
- 上游 PI1(`docs/dispatch/reports/2026-08-07_PI1_yaml_consumption.md`):扫「yaml 里有、lib 里 grep 零命中」的**完全未消费**字段。
- 上游 Q1(`docs/dispatch/reports/2026-08-07_Q1_field_verify.md`):对上述 25 个字段做假阴复核。

**本单要找的是这两轮都逮不到的第三类**——字段名在 lib 里 **grep 有命中**(所以不算"未消费"),但真实取值路径是**写死的字面量常量**,配置形同虚设。

### 活样本(已由 Claude 实锤,请当作判据锚点,不必重复验证)

`data/numbers.yaml:942` 的 `rarity_distribution` 配了 6 档角色稀有度概率(庸才15%/寻常35%/标准25%/资优18%/天才5%/绝世2%),`lib/core/domain/enums.dart:150-157` 六档枚举也齐备,grep `RarityTier` 满屏命中——**但三个生产赋值点全部硬编码 `RarityTier.biaoZhun`**:
- `lib/features/recruitment/application/recruitment_service.dart:99`
- `lib/features/sect/presentation/sect_recruit_handler.dart:110`
- `lib/features/onboarding/application/master_builder.dart:53`

后果:游戏里招募/收徒来的角色**永远是「标准」档**,GDD §4.1 声明为"强制规则"的稀有度分布从未生效,改 yaml 概率不产生任何行为变化。这就是本单要系统性找出的那类背离。

## 二、扫描范围

**配置侧**:`data/` 下全部 `.yaml`(含子目录;`data/narratives/_archive/` 与 `data/lore/_templates/` 可跳过——已确认不进 asset bundle)。

**代码侧**:`lib/` 全部 `.dart`,**排除**:
- `**/*.g.dart`(codegen 产物)
- `lib/features/debug/`(调试/种子/审计工具,允许硬编码)
- 测试目录 `test/`(不在扫描范围)

## 三、判定标准(三档,每条必须落一档)

| 判定 | 含义 | 举证要求 |
|---|---|---|
| **背离(confirmed)** | yaml 有可调字段;生产代码对应取值点是字面量常量,不读该字段;**改 yaml 不改变行为** | yaml `file:line` + lib 硬编码点全部 `file:line` + 一句话「改配置为什么不生效」+ 一句话「玩家侧可观察表现」 |
| **部分背离** | 配置被读取,但**某些分支/某些调用点**绕过它写死了值(如默认值兜底成常量、某一个 caller 传字面量) | 同上,并明确指出哪些路径读配置、哪些路径绕开 |
| **非背离** | 硬编码是合理的(如枚举定义本身、常量数学系数、UI 布局常数、GDD 明确不可配置项) | 一句话理由即可,不必展开 |

**只报前两档进主表**,「非背离」的排查过程写进附录一句话即可(证明扫过,不要长篇)。

## 四、方法建议(可自行调整,但要说明实际用法)

1. 先从 `data/` 逐 yaml 提取「叶子字段名 + 所在 file:line」,建候选清单。
2. 对每个候选字段,查它的 **loader**:`lib/data/` 下有没有把它读进强类型配置对象?(入口如 `lib/data/numbers_config.dart`、`lib/data/game_repository.dart` 等,自行定位)
3. **关键一步**:字段有 loader ≠ 生效。继续查这个配置值在业务层**有没有被真正用到决策上**,还是被同名/同义的字面量常量顶替了。特别留意这几种形态:
   - 赋值处直接写枚举/数字字面量(活样本即此类)
   - `?? <字面量>` 兜底,而配置侧其实永远为 null(等价于常量)
   - 配置读进来只用于日志/展示,决策分支另用写死的阈值
   - loader 解析了字段但结果对象没有任何 caller
4. 概率/分布类字段额外查一步:有没有真的接 **随机源**?本项目确定性随机走 `rngProvider`,**不要**接 `dart:math Random`。配置了概率却找不到任何 roll 逻辑 = 强背离信号。
