## 〇、为什么要这个

2026-08-07 做过一次文档死链全仓扫描,产出底账 `docs/dispatch/reports/2026-08-07_B1_doc_links.md`(报 1092 处死链)。**但那次的脚本放在 /tmp 没入仓,已不可复现**,而且事后复核发现它报的数**严重偏高**,三类系统性假阳性:

1. **398 处**指向 `.gitignore` 明文声明"不入库"的路径(验收截图 / `docs/art/` / `test/tools/output/` 等)。文件在本地磁盘真实存在,只是按策略不进 git。**这不是死链,是合规。**
2. **29 处**是 `*.g.dart` 等 build 产物。那次扫描跑在一个没跑过 `build_runner` 的 fresh worktree 里,导致全判死。
3. **16 处**是 git worktree / 分支名(形如 `docs/equip-baicao-orchestration@25221323`),根本不是文档路径。

**你的任务:写一个把这三类正确排除掉的扫描器,并入仓。**以后任何人跑一条命令就能拿到可信的死链底账。

## 一、扫描算法(照此实现)

### 1.1 范围
- `docs/**/*.md`,**排除** `docs/_archive/`

### 1.2 采集两种引用形态
- **反引号路径**:正文中 `` `...` `` 内形如 `docs/…` `lib/…` `test/…` `data/…` `tool/…` `tools/…` `assets/…` 的 token(允许可选 `./` `../` 前缀)
- **md 链接**:`[text](path)` 与 `![alt](path)` 的 path 部分

> 实测提示:本仓死链**几乎 100% 是反引号形态**,md 链接只有 43 处。但两种都要采。

### 1.3 不扫的内容
- 代码围栏内部(``` 与 ~~~ 包裹的块)
- URL(`http(s)://` `mailto:` `ftp://`)、纯锚点(`#section`)
- 非反引号包裹的裸文本路径(误报率极高)

### 1.4 清洗(按序)
- 剥 `#anchor`
- 剥 `:行号`(形如 `:12` `:12-30` `:12,30` `:12+`)
- 剥已知扩展名之后的字段后缀(如 `data/skills.yaml.powerMultiplier` → `data/skills.yaml`)
- 剥尾部标点(含**中文标点**:`。，；：、」』】)` 与半角 `)。,;:` 及空白)

### 1.5 跳过类(不计入引用,也不计入死链)
| 类 | 形态 |
|---|---|
| 通配 | 含 `*` `?` `{` `}` |
| 模板占位 | 含 `<...>` 或 `[...]` 或 `...` |
| 范围简写 | `a..b` |
| worktree/分支名 | 含 `@` 后跟 6+ 位 hex |
| 前缀简写 | 末段无扩展名且以 `_` 结尾 |
| 单字母/明显占位 | 路径段为 `X` / `foo` / `bar` |
| 出 repo | 以 `../` 越过仓库根、或含 `.claude/projects/` |

### 1.6 存在性判定(**关键改进,别用 os.path.exists**)

用 **`git ls-files`** 建立"仓库已跟踪文件集",判定 `target in TRACKED` 或 `target` 是某个已跟踪文件的父目录。

**理由**:`os.path.exists` 的结果依赖当前工作树的 build 状态(跑没跑 `build_runner`、有没有本地未入库的截图),同一份文档在主树和 fresh worktree 会扫出不同结果——这正是上次报 1092 的根因。用 `git ls-files` 与工作树状态解耦,任何地方跑结果一致。

### 1.7 gitignore 过滤(**关键改进**)

对判定为"不存在"的目标,再跑一次 `git check-ignore --stdin`(批量,别逐个调,会很慢)。命中的归入 **`ignored` 类单独计数,不计入死链**。

## 二、输出

支持两种模式:

1. **默认(人读)**:打印汇总表——扫描文件数 / 引用总数 / 死链数 / ignored 数 / 跳过数,以及按 `docs/` 一级子目录的分布。
2. **`--json`**:输出结构化结果供 diff 比对,建议形状:
```json
{"scanned_files": 0, "refs_total": 0, "dead": 0, "ignored": 0, "skipped": 0,
 "by_dir": {"handoff": 0, "spec": 0},
 "rows": [{"file": "docs/x.md", "line": 12, "target": "lib/y.dart"}]}
```
