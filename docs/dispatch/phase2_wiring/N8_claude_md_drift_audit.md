# N8 · CLAUDE.md 自称 vs 代码实况 drift 审计(只读)

## 背景

`CLAUDE.md` 现为 v1.95,头部堆了约 50 条版本摘要,正文 §5.3 / §5.4 / §6 / §8.1 大量引用**具体符号名与文件路径**。
这类长寿规则文档的行号、路径与「已实装」状态是 drift 高发区——文档自称已收口,代码早已迁位或删除。
历史实证:v1.40 就修过一次「`GameRepository._enforceEncounterSkillRedLines` 已迁到 `encounter_red_lines_validator.dart`」的 drift;
v1.28 修过「`EquipmentRepository.canEquip()` / `TechniqueRepository.canPractice()` 两符号根本不存在」。
**同类 drift 大概率还有**,而每一条都会让后续会话按错误前提干活。

## 目标

逐条核对 `CLAUDE.md` 正文(**跳过头部版本摘要区**,只审 `## 1.` 之后的正文)里所有:

- 提到的 **Dart 符号名**(类 / 函数 / 常量)—— 现在还存在吗?在文档说的那个文件里吗?
- 提到的 **文件路径** —— 还在吗?
- 提到的 **yaml key / 配置字段** —— 还在吗?
- 声称「已实装 / 已收口 / 已激活」的**行为** —— 代码里能找到对应实现吗?

产出偏差表,每行:`CLAUDE.md:<行号>` / 文档原文 / 实际情况(带 `file:line` 或「零命中」)/ 偏差类型(迁位 / 不存在 / 行为不符 / 无偏差不列)。

## 范围围栏(机器可判)

- 改动必须**恰好 1 个文件**:`docs/audit/claude_md_drift_20260826.md`
- `CLAUDE.md` 本身**一行都不许改**(它在禁区清单里)
- `lib/` / `test/` / `data/` 改动数必须为 **0**
- 报告 ≤120 行,**只列有偏差的**,无偏差项不占行

## 禁止的修法

- ❌ 禁止修 `CLAUDE.md`。它是禁区文件,偏差由协调者收口。
- ❌ 禁止「看起来应该还在」——每条结论必须有现跑的 grep 证据。零命中要写明用了什么模式搜的。
- ❌ 禁止只搜英文符号名就下「不存在」结论;本项目大量领域概念用中文命名,先搜中文/领域词确认真实命名。

## [BLOCKED] 出口条件

- 某条文档声称触及 🔴 红级语义(数值红线 / 三系锁死 / 在线=离线)且你发现代码实际行为与之矛盾 → **照常记进偏差表**,但在表末单列「疑似红线偏离」段并标 `[BLOCKED]`,不要自己判定谁对。

## 验收方式

1. `gate.sh <worktree> <base> HEAD --skip-full` 必须 PASS
2. 抽查 5 条偏差,协调者现场复跑同样的 grep 核对
3. 抽查 3 条「无偏差」区域(协调者自选),确认你没漏审

## 硬约束(全部照抄自协调者契约,违反即作废)

**执行端禁区文件**(一行都不许改):`data/numbers.yaml` / `GDD.md` / `PROGRESS.md` / `lib/shared/strings.dart` / `pubspec.yaml`

- **禁 push / 禁 merge / 禁碰 main / 禁 revert**
- commit message 用**中文动宾**,tip 打 `[READY]`(写完待评)或 `[BLOCKED]`(需拍板)
- 收工时工作树必须干净(`git status -sb` 无未提交实质改动、无未跟踪文件)
- 🔴 红级(玩家可见 UI / 数值与成长规则 / schema 迁移 / 删配置字段或功能 / GDD 解释)→ **停 `[BLOCKED]`,禁代拍**
- **数字必须实测**,禁转抄历史、禁凭记忆写 `file:line`;每条引用现 grep 定位
- 搜不到 ≠ 不存在:`git grep -E` 是 POSIX ERE **不认 `\s`**(静默永不匹配);先搜中文/领域词找代码真实命名
