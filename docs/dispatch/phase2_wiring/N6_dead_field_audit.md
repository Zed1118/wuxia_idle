## 关键约束(踩过的坑,照做)

- **「零引用」不等于「废弃品」**:某些资产是目检否决过的破图,某些字段是**待接线**而非死字段。
  每条都要 `git log -S '<标识符>'` 查它的引入/移除历史,并读附近注释,再给判定:
  `死字段(建议删)` / `待接线(有 spec 依据)` / `无法判定`。**无法判定是合法结论,别硬猜。**
- **否定式 grep 不是存在性证明**:搜不到 ≠ 不存在。搜之前先确认代码里的**真实命名**
  (中文命名、领域词、动态拼接的 key 都会让直觉搜法落空)。**动态拼 key 的读取点必须专门找一遍**。
- `git grep -E` 是 POSIX ERE,**不认 `\s`**(会静默永不匹配)。
