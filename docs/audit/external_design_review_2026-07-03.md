## 0. 汇报定位与方法论

### 0.1 项目现状判断

这不是一个需要"设计机制"的早期项目，而是一个**已进入 1.0 长线打磨期、设计成熟度极高**的项目：

- GDD 体系完备（v1.18，12 章节全覆盖），红线纪律严明（反主流清单 / 三系锁死 / 数值两层红线 / 在线=离线 / 不硬编码）
- 核心系统几乎全部实装：境界 49 级 / 三流派克制 / 装备强化+共鸣+开锋 / 心法修炼度 9 层 / 师徒传承+飞升 / 心魔 / 轻功 / 群战 / 第二条主线 Ch4-6 / 江湖恩怨+声望 / 帮派门派
- 内容量已超 Demo 目标（主线 6 章 ~26.5k 字 / 装备 35+→目标 80 / 心法 21→目标 50）
- 平衡已过两轮审计（战斗链路🟢 / 成长曲线🟢 / 经济🟢）

### 0.2 设计师能提供的增量价值

对一个已成熟的项目，设计师的价值不在"加功能"，而在四件事：

1. **识别单一最优策略风险**——挂机品类最容易死在"一套 build 通关"，数值连乘下的策略掩盖
2. **破解核心矛盾**——买断制 + 反主流（无日课/登录/体力/战令）+ 在线=离线，传统留存手段全部禁用，留存靠什么？
3. **针对 PROGRESS 挂账的待拍板设计问题给方案**——终局 Boss 偏软、心魔惩罚未 wire、群战数值调优
4. **评估中长期扩展的可行性边界**——什么能扩、什么扩了会破红线

本汇报按此四条展开，**每一条都落到可执行建议 + 风险标注 + 红线兼容性判断**。

## 1. 核心玩法机制诊断

### 1.1 现有核心循环评估

GDD §9 的 5 阶段循环（开场看昨晚 → 调度门人 → 战斗推进 → 收尾安排 → 离线挂机）是挂机品类的**优秀骨架**。"上线第一屏 = 昨晚发生的事"这个设计尤其好——它把"打开游戏"从"清红点义务"变成"读一段故事延续"，直接兑现了反主流承诺。

**循环的健康度判断**：✅ 短期（单局 5-30min）与中期（单日 1-3 次）循环健康；⚠️ 长期循环（通关后数周）存在留存真空，见 §5。

### 1.2 玩家决策点盘点

把"玩家实际在做什么决策"摊开看：

| 阶段 | 决策点 | 决策权重 | 现状评估 |
|------|--------|---------|---------|
| 调度 | 闭关地图选择（5 张） | 中 | ✅ 产出差异化清晰（古剑冢掉装备/藏经阁悟心法/瀑布涨内力） |
| 调度 | 阵容配置（3 人 + 流派搭配） | 高 | ⚠️ 见 §1.3 风险 2 |
| 调度 | 心法主修+辅修搭配 | 高 | ✅ 散功 50% 代价让换主修是重决策 |
| 调度 | 装备开锋 build（4 选 3） | 高 | ⚠️ 见 §2.2 风险 C |
| 战斗 | 拖招放大招（单体/aoe 选择 + 目标指定） | 中 | ⚠️ 见 §1.3 风险 1 |
| 战斗 | 破招锁定蓄力中敌人 | 中 | ✅ 即拖即放 + 破招窗口是有趣的即时决策 |
| 收尾 | 闭关时长档位（1/4/12h）+ 时辰/节气对齐 | 中 | ✅ 时间锚点是好的长期决策 |

**结论**：决策点数量充足，但**高权重决策的策略深度存疑**——部分决策可能存在明显最优解，使"决策"退化为"操作"。

### 1.3 策略深度风险

#### ⚠️ 风险 1：半手动战斗的决策深度不足

半手动战斗的核心交互是"拖招放大招"。但决策的趣味性取决于：**放大招的时机/目标是否真的有取舍？**

当前伤害公式连乘（基础 × 修炼度 3.0 × 克制 1.25 × 暴击 2.0 × 防御 × 境界差 2.5）下，满配 build 一回合可秒杀终局内容（GDD §5.4 已承认是有意爽感）。这意味着：

- 如果大招能秒杀，"何时放"和"放谁"的决策被削弱——反正一招解决
- aoe 大招无衰减无均摊（§5.8 A 方案）→ 群战时"永远放 aoe"可能是最优解，单体大招沦为摆设
- 高耗内 + 长 CD 是 aoe 的唯一制衡，但若内力回复速度够快或战斗够短，制衡失效

**建议**：
1. **aoe 制衡验证**：用 `balance_simulator` 跑"内力回复速率 × 战斗时长 × aoe CD"的矩阵，确认 aoe 不会在典型战斗中"每波都放得出来"。若失效，考虑 aoe 引入"目标数内力消耗递增"（每多 1 目标 +30% 内耗）而非衰减伤害——保爽感、加成本。
2. **大招决策的真实博弈**：让部分终局 Boss 设计为"大招窗口期"机制——Boss 蓄力时只有大招能破招、平时大招被吸收/反伤。这样"大招何时放"成为真正的资源博弈，而非 DPS 最大化。心魔关卡的"克己语义（难赢但不输）"已是这个方向的雏形，可推广。
3. **自动战斗的可看性**：挂机刷已通关关卡时玩家在看什么？建议战斗日志做成"关键瞬间高光"流（破招/暴击/反杀/濒死翻盘自动标记），让挂机也有"看集锦"的体验，而非干看伤害数字飘。

#### ⚠️ 风险 2：阵容流派搭配的策略空间未充分释放

3v3 阵容 + 三流派克制（刚猛→阴柔→灵巧→刚猛），理论上"全刚猛 / 全阴柔 / 混搭"应各有打法。但当前：

- 流派附加效果是固定的（刚猛震伤+500 / 阴柔内伤 3×200 / 灵巧暴击+20%），缺乏"流派间协同"
- 心法相生组合（§4.5）是"主+辅特定搭配触发 buff"，这是好的协同设计，但目前只有 5 个（目标 10-15），且一旦被 Wiki 攻略化就成"必配"

**建议**：
1. **扩心法相生到 10-15 个时，引入"冲突相生"**——某些相生组合互斥（如"阴阳调和"与"丐帮传承"不能同队共存），迫使玩家在阵容层面做流派取舍，而非堆叠所有 buff。
2. **流派协同的阵容层效果**——3 人同流派解锁"流派阵法"（全刚猛=震伤共振 / 全灵巧=残影连击 / 全阴柔=内伤蔓延），让"全同流派"成为有收益也有弱点的 build（全刚猛被全阴柔阵容克制时崩盘）。这增加阵容搭配的策略维度。

## 2. 游戏平衡性诊断

### 2.1 制衡关系盘点

| 制衡轴 | 机制 | 制衡强度 | 风险 |
|--------|------|---------|------|
| 流派克制 | ±25% + 附加效果 | ⚠️ 偏弱 | 见 §2.2 风险 A |
| 境界差距 | ×2.5 / ×0.3 / ×0.05 | ✅ 强（可能过强） | 见 §2.2 风险 B |
| 装备阶锁 | 三系一一对应 | ✅ 强 | 无 |
| 散功代价 | 内力-50% + 修炼度-50% | ✅ 适当 | 无 |
| aoe 制衡 | 高耗内 + 长 CD | ⚠️ 待验证 | 见 §1.3 风险 1 |
| 吸血制衡 | 无上限 | 🔴 缺失 | 见 §2.2 风险 C |

### 2.2 单一最优策略风险

#### 🔴 风险 A：流派克制被数值连乘掩盖

伤害公式最终值 = 基础 × 修炼度(1.0~3.0) × 克制(0.75/1.0/1.25) × 暴击(1.0~2.5) × (1-防御) × 境界差(0.05~2.5)。

**问题**：境界差系数 2.5 是流派克制 1.25 的 2 倍，修炼度 3.0 是它的 2.4 倍。在跨境界战斗中，"高 1 阶"的收益（×1.4）就接近"克制"（×1.25）。这意味着**玩家追求境界的收益 > 追求流派克制的收益**，克制机制在策略权重上被边缘化。

**建议**：让流派克制系数**随境界差递增**——同境界对决时克制 ±25%，每差 1 阶克制效果放大到 ±35%，差 2 阶 ±50%。逻辑：高手过招流派相克更致命（武侠小说的"以柔克刚"只在同档次才成立；碾压局无所谓克制）。这样：
- 低境界碾压局：克制无关紧要（符合直觉，反正秒杀）
- 同境界对决：克制成为关键策略（增加终局对决的策略权重）
- 数值上不破红线（克制极值 ±50% 仍小于境界差 ×2.5）

#### ⚠️ 风险 B：境界碾压摧毁策略空间

境界差 ×2.5（差 2 阶）/ ×0.05（差 3 阶免疫）非常陡峭。这有效防住了"低境界堆装备碾压高境界"（三系锁死也帮了忙），但副作用是：**一旦玩家境界领先，所有策略都失效**——反正碾压。

GDD §5.4 已承认"终局极值 build 一回合秒杀终局内容"是有意爽感。这是合理的产品判断，但**留了一个口子**：如果终局内容全是数值型 Boss，满配玩家就只剩"看秒杀动画"，策略空间归零。

**建议**：终局内容（爬塔 25-30 层 / 心魔 7 关 / 终局周目进化）中，**至少 1/3 设计为"数值碾压无效"的机制型关**：
- 破招窗口型：Boss 蓄力期才受伤害，平时免疫（护法结界已试水，可扩展）
- 限时生存型：扛过 N 回合即胜，DPS 无意义
- 多目标优先级型：必须按顺序击杀，否则 Boss 狂暴回血
- 内力管理型：Boss 吸内，大招放不出来，考验普攻+小技能循环

这些关让满配玩家也必须"动脑"，而非"动数值"。PROGRESS 挂账的"终局 Boss 100% 胜偏软"正是这个问题的表征——见 §7 方案。

#### 🔴 风险 C：吸血开锋可能形成永动 build

开锋吸血 slot1=10% / slot2=15%（§6.5，slot1+slot2 不能同类型，所以单角色最多一个吸血槽）。但 10-15% 吸血 + 共鸣度 +30% + 高攻击 build 下：

- 单次普攻伤害若 8000，吸血 15% = 回血 1200/击
- 出手速度 200+ 时，每秒 2 次攻击 = 回血 2400/s
- 玩家血量上限 ~16000，相当于 7 秒回满

在长战斗（爬塔高层数 / 群战多波次）中，这可能形成"打不死"的永动 build，摧毁挑战性。numbers.yaml 中**未见吸血上限**。

**建议**：
1. **吸血设上限**：单次吸血 ≤ 造成伤害的 15%（已是上限）且 ≤ 角色最大血量的 5%（防暴击一发回满）。或引入"吸血递减"：连续吸血后效果衰减 30%，3 回合后恢复。
2. **吸血 build 的设计性弱点**：让吸血开锋与"破甲"互斥已存在（slot 约束），但可进一步——吸血 build 对"内伤 debuff"（阴柔）更敏感（内伤阻止回血），形成 build 间的三角制衡。

#### ⚠️ 风险 D：防御率上限 35% 使破甲 build 对低境界对手无用

防御率 5%（学徒）→ 35%（武圣），破甲 15-20%。对学徒对手破甲收益几乎为零（破 5% 的 20% = 1%），对武圣对手才有意义（破 35% 的 20% = 7%）。

**这其实是好的设计**——破甲对强敌才有价值。但需要在终局内容中**确保有高防 Boss 存在**，否则破甲开锋永远是次选。建议终局 Boss 数值配置时，部分 Boss 防御率刻意拉到 40-45%（突破境界表上限，作为 Boss 特性），让破甲 build 有用武之地。

## 3. 系统设计诊断

### 3.1 成长系统（多轴成长）

| 成长轴 | 节奏 | 产出方式 | 取舍空间 |
|--------|------|---------|---------|
| 境界 49 级 | 慢（经验） | 闭关+战斗+经验丹 | 无（线性推进） |
| 修炼度 9 层 | 中（使用次数） | 该心法招式使用次数 | ✅ 换心法重置 |
| 装备强化 +49 | 慢（材料） | 磨剑石+心血结晶 | 无（线性） |
| 共鸣度 4 阶 | 慢（战斗次数） | 出战装备累积 | ✅ 换装备清零 |
| 开锋 3 槽 | 一次性决策 | +10/+15/+19 解锁 | ✅ 4 选 3 |
| 奇遇属性 +5 | 极慢（生涯上限） | 奇遇 | 无 |

**评估**：✅ 成长轴丰富且节奏分层（快/中/慢/一次性），每个轴有独立的"何时推进"逻辑。⚠️ **风险**：6 个成长轴全部"都要拉满"，玩家可能感到"永远没完"。买断制无内购下，这种"无限成长"反而是优点（长线目标），但需确保**不同 build 对应不同终局内容**，让"拉满"有方向感而非盲目堆数值。

**建议**：强化"build → 终局内容"的映射——
- 吸血 build → 适合多波次群战（续航优势）
- 破甲 build → 适合高防 Boss 关
- 速度 build → 适合限时关
- aoe build → 适合群战
- 单体爆发 build → 适合单 Boss + 破招窗口关

让玩家"为了打通某关去配 build"，而非"一套 build 通关所有"。这需要终局内容的机制多样化（§2.2 风险 B 的建议直接服务于此）。

### 3.2 经济系统

货币银两 + 磨剑石 + 心血结晶 + 经验丹 + 秘籍。已校准（PROGRESS 经济链路🟢）。

**评估**：✅ sink 设计合理（强化消耗、商店购买材料、经验丹动态标价防套利）。⚠️ **风险**：在线=离线下，经济产出是时间函数，**玩家缺乏"主动选择去刷什么"的决策**——挂机产出是固定的，玩家无法"我今天特别缺磨剑石，去古剑冢多刷"。

**建议**：5 张闭关地图的产出差异化已存在（古剑冢掉装备 / 藏经阁悟心法 / 瀑布涨内力），但**差异化强度可能不够**。建议量化各地图的"目标资源产出占比"——古剑冢应让磨剑石产出占比 >60%，藏经阁让心法相关产出 >60%——让"去哪闭关"成为真正的经济决策（我缺什么就去哪）。当前若各地图产出太平均，差异化就是名义的。

### 3.3 进度系统

主线 6 章 + 爬塔 30 层 + 闭关 5 地图 + 奇遇三通道 + 心魔 7 关 + 轻功 5 关 + 群战 5 关。

**评估**：✅ 内容量充足且分层（主线推进 / 爬塔挑战 / 闭关养成 / 奇遇随机 / 心魔突破 gate）。⚠️ **风险**：进度系统间的**关联性**可以更紧——目前各系统相对独立（主线归主线、爬塔归爬塔），缺乏"打通 A 解锁 B 的关键能力"的跨系统依赖。

**建议**：增加跨系统钥匙——
- 爬塔某层奖励解锁某条心法相生组合（让爬塔有"非排名"动机）
- 心魔关突破后解锁某张闭关地图的"深层"（高产出高风险版）
- 第二条主线 Ch4-6 的遗物 hook 已有（小铜镜/玉佩），可扩展为"集齐某遗物组合解锁隐藏 Boss"

这种跨系统钥匙让进度感是"网状"而非"线性"，增加探索动机。

## 4. 玩家体验目标与留存（核心矛盾）

### 4.1 目标受众与核心体验（已明确，无需调整）

GDD §1.3 已锁定：厌倦氪金手游的武侠爱好者 / 轻度沉浸型 / 单机买断制付费者。核心体验：水墨武侠 + 挂机养成 + 半手动战斗爽感。**这个定位精准，无需改动。**

### 4.2 核心矛盾：反主流红线内的留存

这是整个项目**最高的设计挑战，也是最大的差异化护城河**。

传统手游留存靠：每日任务 / 登录奖励 / 体力 / 战令 / 抽卡 FOMO / 社交压力。本项目**全部禁用**（§2.1）。叠加买断制无内购 + 在线=离线，意味着：

- 玩家没有任何"上线义务"——想玩才玩，关游戏无惩罚
- 玩家没有任何"错过焦虑"——离线收益等同在线，不抽卡不刷限定
- 玩家没有任何"社交攀比压力"——纯单机，仅爬塔排行榜

**这恰恰是目标受众想要的**——他们正是被这些机制赶走的。所以这不是 bug 是 feature。但**通关后（主线 6 章 + 爬塔 30 层 + 心魔 7 关全通）玩家靠什么回来？** 这是必须回答的问题。

### 4.3 红线内留存方案

留存不靠"每日义务"，靠"想回来看看"。以下是**全部兼容反主流红线**的留存锚点：

| 留存锚点 | 机制 | 现状 | 强化建议 |
|---------|------|------|---------|

**关键判断**：本项目的留存护城河是**"情感锚点 + 代际叙事"**，不是"每日义务"。玩家通关后会回来，是因为想看"我的门派第三代祖师的故事"、想看"那柄跟了师父一辈子的剑传到徒弟手里又添了什么典故"、想看"江湖编年史里又记了什么"。**这条路径是对的，需要把编年史 + 代际典故从"长期愿景"提到"1.0 打磨期核心交付"。**

## 5. 中长期可持续性

### 5.1 内容扩展可行性

✅ **架构天然支持扩展**：yaml 驱动（data/*.yaml），加内容不动代码。第二条主线 Ch4-6 已验证单端产能（每章 ~5-6k 字，opus 单批 ~50min）。

⚠️ **风险**：心法相生 / 武学领悟的"隐藏组合"一旦被攻略 Wiki 化，**发现感消失**。这是所有"隐藏内容"设计的通病。

**建议**：
1. **节日限定奇遇**作为周期性新鲜感——节气日 +30% 已实装（§7.3），8 节日 encounter 已落。可扩展"节气限定隐藏组合"——清明/冬至触发特定心法相生，全年仅窗口期可解锁，制造"应景发现"而非" Wiki 一次性挖完"。
2. **动态典故模板扩到 20+**——战斗事件触发的延续典故是"玩家独有"内容，Wiki 抄不走（因为依赖玩家自己的战斗史）。这是反 Wiki 化的最佳杠杆。

### 5.2 留存激励的可持续性

多代飞升是核心留存引擎。但需注意：**代际之间必须有"质变"而非只是"数值重置"**。如果第二代祖师只是"重新练一遍 + 不同流派"，玩家第二代就乏了。

**建议**：每代祖师引入**独有变量**——
- 第一代：标准武侠成长
- 第二代：师承遗物 + 父辈典故继承（剑上多了"曾饮 X 之血"的延续典故）
- 第三代：跨代心法相生解锁（祖师+徒弟心法组合，第三代才能触发）
- 第四代+：江湖编年史积累到一定厚度，解锁"门派传奇"隐藏结局

让"代际"不只是周目数，而是**叙事厚度的累积**。

### 5.3 扩展的可行性边界（什么不能扩）

- ❌ **不能加 PVP**——已切除（v1.18），方向正确。PVP 会强制引入战力攀比，破反主流基调。
- ❌ **不能加体力/日课/战令**——永久红线。
- ⚠️ **谨慎扩在线=离线的例外**——半手动战斗的"手动单步推进新关卡"是内容 gate 而非留存机制（§2.2 已澄清），但任何进一步的"在线优势"都会破红线。
- ✅ **可大胆扩**：剧情内容 / 装备心法数据 / 典故 / 奇遇 / 心法相生 / 代际叙事 / 编年史 / 闭关地图 / 机制型 Boss。

## 6. 待拍板设计问题方案建议

针对 PROGRESS.md 挂账的待拍板设计问题，给出方案：

### 6.1 终局 Boss 100% 胜偏软（PROGRESS 2026-07-01 挂账）

**问题**：on-level 队 100% 胜，终局 Boss 缺乏挑战，满配玩家无策略空间。

**方案**：引入**机制型 Boss**，分三类部署到终局内容：

| 机制型 | 设计 | 适用场景 |
|--------|------|---------|
| **破招窗口型**（护法结界已试水） | Boss 蓄力期才受全额伤害，平时伤害×0.15；护法小怪存活时主 Boss 减伤 | 爬塔 25/30 层、终局周目 Boss |
| **多阶段型** | Boss 分 2-3 阶段，每阶段流派/弱点变化，逼玩家阵容应变 | 心魔 7 关（已有"克己"语义基础） |
| **限时/生存型** | N 回合内不死即胜 / N 回合内打出 X 伤害，DPS 无意义 | 爬塔特殊层、隐藏 Boss |

**红线兼容**：✅ 纯机制层，不碰数值红线（Boss HP 仍 ≤60000），不破三系锁死，不破在线=离线。

**优先级**：🔴 高——这是终局策略空间的唯一解，且 PROGRESS 已挂账待拍板。

### 6.2 心魔战败惩罚未 wire（PROGRESS 2026-06-16 审计 M6 挂账）

**问题**：`InnerDemonFailurePenalty`/`InnerDemonResidueDebuff` 配置已定义，但代码层从未 wire，战败无惩罚。

**方案**：建议 wire，但采用**温和惩罚**（已设计值）：
- 战败：内力 ×0.85 / 主修修炼度 ×0.9 + "心魔余毒" debuff（闭关 8h 清）
- 不归零、不破装备、不降境界——符合"强化不破防降级"的反挫败哲学

**设计理由**：心魔是境界突破的 gate（§12.1），若无惩罚则 gate 形同虚设，"克己语义（难赢但不输）"失去张力。但惩罚必须温和——心魔本身就是"战胜自己"的叙事，战败应是"暂受挫折"而非"崩溃"。

**红线兼容**：✅ 不破任何红线。惩罚值已在 numbers.yaml 配置，仅 wire 代码路径。

**优先级**：🟡 中——影响心魔关张力，但不阻塞其他系统。

### 6.3 群战 R5.1 数值调优（PROGRESS 2026-05-24 挂账）

**问题**：stage_03/04/05 玩家 3 vs 累计 17-26 敌，maxTicks=2000 不足，全 draws。

**方案**：采用"wave 间部分回血"——
- 每个 wave 间，玩家 HP 回复 30%（不回满，保留多波次压力）
- 内力保留（不做 reset，逼玩家管理内力跨波次）
- 后波敌方数值递减 10%（模拟"以少胜多"的体力叙事，而非硬堆数值）

**设计理由**：群战核心体验是"以少胜多的悲壮感"（narrative 已写"不躁/不乱/不溃/不让/不忧"）。全 draws 说明数值压力过载，"悲壮"变"打不完"。wave 间 30% 回血保留压力又给希望，后波递减模拟敌方疲惫。

**红线兼容**：✅ 纯数值调优，不破红线。

**优先级**：🟡 中——影响群战体验，但不阻塞主线。

### 7.2 设计师总结

**这个项目的设计成熟度在独立游戏里属于上游**。红线纪律之严明（反主流清单 + 三系锁死 + 两层数值红线 + 在线=离线 + 不硬编码）在同类项目中罕见，且已通过多轮审计验证落地。GDD 作为单一设计真相源的维护质量也高。

**最大的设计机会**在"反主流红线内的留存"——这是品类级的差异化。当所有挂机手游都在用日课/体力/抽卡逼玩家上线时，这个项目用"代际叙事 + 江湖编年史 + 装备情感绑定"留人，是对目标受众（被氪金手游伤透的武侠爱好者）最精准的回应。**这条路是对的，需要把编年史和代际典故从"长期愿景"提到"1.0 核心交付"。**

**最大的设计风险**在"终局单一最优策略"——满配 build 秒杀终局 + aoe 无衰减 + 吸血无上限，三者叠加可能让终局退化为"看秒杀动画"。解决路径不是削数值（爽感是产品主旋律），而是**用机制型 Boss 给策略空间留口子**——数值碾压对普通关，机制应对终局关。

**一句话**：把"情感留存"和"机制型终局"做透，这个项目就能在买断制武侠挂机这个细分赛道上立住。
