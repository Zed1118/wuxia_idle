# N3 · 玩家侧战斗立绘色调审计(补 BACKLOG 一#14 拍板依据,2026-08-05 夜班)

> 起因:批 C 终拍时用户观察「我方 3 角色灰蒙蒙,敌方新 Boss 有彩色元素」。
> 方法:PIL HSV 统计(alpha>50 像素;灰占比 = S<0.15 像素比;色相桶 8 分)。

## 一 · 范围定论:玩家侧战斗立绘全集恰为 3 张,无隐藏名单

`_playerFallbackStandee`(`character_avatar.dart:1053-1061`)按站位 `slotIndex % 3` 轮换
`battle_founder_v2 / battle_first_disciple / battle_second_disciple`——**任何角色**(记名弟子/降将/收徒)上场都复用这 3 张。收徒候选图(recruit_candidate_* / sect_candidate_*)不上战斗屏。**若拍方案 a(重出),范围就是 3 张,1 批 image_gen 完事,无需改代码字段。**

## 二 · 量化:「灰蒙蒙」的真身是色相单一,不是饱和度低

| 立绘 | 灰占比 | S 均值 | 主色相分布 |
|---|---|---|---|
| battle_founder_v2(祖师) | 42% | 0.16 | 红99%(暖土) |
| battle_first_disciple(大弟子) | 1% | **0.38** | 红84% 橙16% |
| battle_second_disciple(二弟子) | 0% | **0.44** | 红96% 橙4% |
| 批C 8 Boss 均值 | 27-78% | 0.11-0.24 | **普遍冷暖双色相** |

- 大弟子/二弟子**饱和度反而高于全部新 Boss**(0.38/0.44 vs ≤0.24)——「提饱和」方向从数据上直接否定
- 玩家 3 张色相 ≥95% 挤在红橙桶(土褐/灰绿泥土系),**零冷色相**
- 新 Boss 每张有冷色相块(青/绿占 13-77%):药叉红34+青31 / 金刚红60+绿26 / 剑隐绿48+橙22 / 判官青56+红27 / 剑侍绿77+青13……**「彩」的观感来源 = 冷暖双色相对比**
- 近批参照(断魂庄 3 张)同为双色相结构;旧代敌(battle_jianghu_a 红94%)与玩家 3 张同病——代际特征,非阵营设计

## 三 · 对方案 a 的出图规范建议(若拍板)

- 保水墨厚涂底 + 每张配**一个冷色相主块**(青/绿/蓝袍或饰)+ 绛红点缀,对齐批 C 双色相结构
- 三人色相错开(如祖师青灰/大弟子青绿/二弟子蓝紫)保队伍内区分度
- 沿批 C 管线:参考锚喂入 + bbox 批次尺度归一 + fraction PIL 实测,identity 单文件接线体例
