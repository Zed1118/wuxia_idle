## 为什么做

此前主线立绘的验收只到**素材层**（尺寸 / 四角 alpha / 脚底 fraction / 逐图目检原图），
真机战斗屏目检长期挂在账上——PROGRESS 里 Ch16「立绘真机战斗屏未目检」、
Ch17/Ch18「两章立绘均未真机战斗屏目检」、Ch20/Ch21 同样在账。

**这个空档不是形式主义**：本夜第一件事就是在 Ch21 逮到 `jueding_lunjian_houren`
**左脚整只悬空 164px**，而素材层九判据全绿（它只验 alpha 包围盒**底沿**，单脚悬空不改底沿）。

## 方法

```
visual_capture.sh --route battle_audit_stage_<NN>_<MM> --resolutions 1280x720 --background
```

真 `ScenarioLauncher` + 真 stage 背景 + `startPaused` 冻结首帧；
1280×720 逻辑 = 2560×1440 物理。判据取各章 `build/dispatch/ch*_art_*` 派单书原文题眼。

复核走两层：
1. **接触印相表**批量过眼（每关裁敌立绘带 + 脚下地面）——抓悬空 / 裁切 / 道具错 / 兵器错这类粗缺陷；
2. **逐张放大**核验题眼——用于当章判据最细的那几张。

## 结论

**105 关全部 PASS，除已修的论剑后人外零缺陷。**

逐章抽检到的题眼命中（举证，非全列）：

- Ch17 黑风刀客：须发结砂壳 / 背风侧被砂打白 / 阔背刀反手拄地贴小腿 / 零特效
- Ch17 卷沙手：两手一上一下掌心相对如抱不可见之柱 / **眼睛盯着自己的手不看观众** / 无砂柱特效
- Ch17 沙海领路人：绳绕小臂两圈 + 绳头坠旧铜环沉垂 / 全身无鞘装兵器
- Ch18 城下候客：宽袖沉甸甸下坠（暗示袖中兵器而画面不画）/ 脚边粗陶碗
- Ch18 西凉霸主：雪白须发束得整齐 / 指节粗大骨节分明 / 全身无兵器 / 无「反派感」
- Ch20 补墙匠：手与墙同色（干泥糊到肘弯）
- Ch20 守关老将：刀身暗沉如铁门闩、零反光零锋线高光
- Ch21 拦径老仆：草鞋磨穿的洞 + 衣襟别的缝衣针
- Ch21 循符少年：嘴唇冻白（**像素级复核**：唇红度 32.5 < 两颊 43.9，正常唇色应反向）

## 顺带澄清的三处「看着像缺陷、实为设计」

1. **09_03 / 10_03 蜃楼幻境角色半透明消散** —— 幻境设定，非抠图残缺。
2. **12_05 坐姿立绘** —— 该角色本就是坐着的老者。
3. **16_02 兜帽罩脸** —— Ch16 守镜人既定设定，到 Ch19 才掀帽露脸（剧情揭示时刻）。

## 顺带修正的一条启发式

「同批立绘纵跨应收敛在窄带」这条（源自 Ch21 摆渡老手首版只占 1127px 被退回重构图）
**只对单人立绘成立**。实测 Ch18 纵跨带宽 1223–1497、最矮/最高 **0.817**，
最矮的 `yangguan_san_dizi` 是**三人合图**（派单书原文即写「这张是三个人」），
个体必然小于单人立绘——与「单人却画小了」性质不同，不构成缺陷。
