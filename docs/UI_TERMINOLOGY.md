# 正式界面术语与文案规范

> 适用范围：正式玩家界面、弹窗、战报、提示与可见存档信息。  
> 不约束 Dart 类型名、YAML 字段、测试描述、开发验收路由与数值红线工具。

## 基本原则

1. 水墨武侠语境优先，避免把内部英文标识、对象文本或数据键直接展示给玩家。
2. 同一概念在正式界面使用同一称谓；不同系统概念不因字面相近而强行合并。
3. 短标签优先清楚，长说明优先完整；不为追求古风牺牲可理解性。
4. 数字、时间和进度必须带明确单位，不依赖颜色传达唯一信息。
5. 中文句子使用全角标点。代码、版本号、文件名和专有缩写可保留半角字符。

## 统一写法

| 概念 | 正式界面写法 | 说明 |
| --- | --- | --- |
| Boss | 首领 | 可用“小首领 / 大首领”；`Boss` 仅留在开发与配置语境 |
| 等级 | `Lv12` | `Lv` 与数字之间不加空格或句点 |
| 存档槽 | 槽位 1 | 不显示 `slot 1` |
| 存档版本 | 版本 0.26.0 | 不显示孤立的 `v0.26.0` |
| 招式 | 招式 / 武学 | 正式界面不用“技能”；不显示 `skill_xxx`、`skill ID` |
| 境界限制 | 需第 N 阶，当前某境界 | 不显示内部 `tier` 字段名 |
| 实际时长 | 小时 / 分钟 | 用于离线、调息、结算等真实计时，不缩写成 `h` 或“时” |
| 世界时序 | 时辰 | 仅用于江湖日历、昼夜与叙事时间 |
| 主线重开 | 周目 | 表示主线重复推进与异势 |
| 九霄塔循环 | 轮回 | 表示爬塔独立循环，不与周目混用 |
| 角色成长值 | 经验 | 数值入账使用“经验”；叙事可用“修为”“阅历” |

## 错误与兜底

- 玩家错误提示说明“发生了什么”和“可以怎么做”，不展示异常对象、堆栈、内部 ID 或数据键。
- 缺失定义使用“招式资料暂不可用”等产品化兜底；具体 ID 只进入开发日志。
- 无法恢复的操作提示使用“请稍后重试”，不承诺系统并未执行的修复动作。

## 保留的概念边界

- “周目”和“轮回”分别属于主线与九霄塔，含义不同。
- “小时”和“时辰”分别表示实际计时与世界叙事时间，含义不同。
- “经验”“修为”“阅历”不全局替换：数值结算强调经验，角色境界与叙事语境可使用修为或阅历。
