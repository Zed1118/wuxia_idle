## 踩坑提醒

- **CI 首跑全绿是这个项目的特例，别当通例**：靠无 golden + 无 Android + Isar download:true 跨平台 + pub 镜像可达四条同时成立。改 CI（换 runner / 加 golden / 动 lock 源）时任一条破坏都可能触发 memory `flutter_ci_local_green_red_divergence` 五坑。

- **gh pr merge --delete-branch 在 bg worktree 会残留远端分支**：本地 git 删分支步骤因 main 被主 worktree 占用而报错，远端合并成功但远端分支需手动 `git push origin --delete`。
