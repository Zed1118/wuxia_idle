# 战斗自动轮转谱口径修正

## 目标

让纯自动观战界面只展示玩家角色会被 `BattleAI` 主动选择的招式，避免把仅限点选的绝招标成“可用”。

## 切片

1. 以组件测试复现仅限点选绝招出现在自动轮转谱的问题。
2. 轮转谱过滤 `requiresManualTrigger` 招式；保留普通自动技、合击技和留作破招的自动技。
3. 验证纯手动招式角色回落“只运周天”，混合配置只展示自动招式。
4. 运行战斗测试全集与静态分析，冻结 `[READY]` 稳定点。

## 验收

- 自动轮转谱不出现 `requiresManualTrigger: true` 的招式。
- 混合技能配置仍展示自动招式及其状态。
- 无可自动轮转招式时展示既有“只运周天”占位。
- `test/features/battle` 全绿，`flutter analyze --no-pub` 无问题。

## 完成记录

- 自动轮转谱已排除 `requiresManualTrigger` 招式，混合配置仍展示自动技。
- 新增仅点选绝招与混合技能组件回归，并把旧冷却断言改为自动强力技。
- 战斗测试全集：741/741 通过。
- 静态分析：`No issues found!`。
