## 踩坑提醒

- **`gh pr view --json merged` 字段不存在**，字段名错会让整条 `&&` 链静默中断后续命令（本会话踩到，误以为 push 失败）。查合并态用 `--json state,mergedAt,mergeCommit`。
- **CI 轮询别用 `gh pr checks`**（pending 时返回非 0 会搞挂 until/for 循环），用 `gh pr view --json statusCheckRollup` 轮询，本会话 5 次命中 settle。
- **`git ls-remote` 与 `git branch -r` 会不一致**：远端分支删除后本地 remote-tracking ref 仍在，须 `git fetch --prune` 才消失。判断远端真实状态以 `ls-remote` 为准，别信 `branch -r`。
- **别把「抬 cap」读成「玩家能到那一层」**：全内容参考路线实测终态 Lv121 = **绝对层 13**（三流·化境），cap 42 是成长上界不是到达点，玩家靠挂机爬境界（缺口 4425 EXP ≈ 37 天墙钟）。已写进 spec §2 防后续误判。
